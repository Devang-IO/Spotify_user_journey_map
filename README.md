# 🎧 Spotify Mobile App – User Journey Map (Case Study)

Welcome to the official repository for the **Spotify Mobile App User Journey Case Study**. This project presents a detailed journey of a new user using the Spotify mobile app, capturing their experience, emotional states, and pain points across various interaction stages.

---

## 📌 Overview

- 🎯 **Goal:** Analyze the user experience of Spotify's mobile app from awareness to retention.
- 📱 **Platform:** Mobile App (iOS & Android)
- 💡 **Focus:** Emotional UX journey, pain points, and UI improvement opportunities
- 🧠 **User Type:** New Spotify user (Student, 22 years old)

---

## 🧩 Journey Stages

| Stage       | Description                            |
|-------------|----------------------------------------|
| Awareness   | User discovers Spotify via social media |
| Sign-Up     | Creates a new account                   |
| Onboarding  | Learns the app UI & settings            |
| Listening | Paid attention to user behaviors, frustrations, and motivations.     |
| Discovery         | Identified user needs through research, analysis, and insights. |
| Retention   | Forms habits or drops off               |

---

## 📈 Emotional Metrics

A horizontal timeline chart displays the emotional journey with emoji labels per stage. Peaks in happiness and delight are annotated with specific UI references (e.g., “Ad disrupted experience”).
